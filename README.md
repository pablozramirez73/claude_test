# SEGNO — Traduttore LIS Real-Time per Telegram

> Le mani parlano. Telegram le ascolta.

SEGNO è una Mini App di Telegram che traduce la Lingua dei Segni Italiana
(LIS) in testo e voce in tempo reale, on-device, direttamente dentro le
chat. Vedi la specifica di prodotto completa in [`docs/PRD.md`](docs/PRD.md).

## In questa repository

- [`docs/PRD.md`](docs/PRD.md) — specifica di prodotto (problema,
  architettura, roadmap, monetizzazione).
- [`apps/segno-miniapp`](apps/segno-miniapp) — POC del primo gradino
  della roadmap (Week 1-3): traduzione di segni statici con MediaPipe
  Holistic, come Mini App Telegram. Vedi il README dell'app per come
  avviarla.

## Stato

Prima stesura — MVP Concept. Il codice implementa il POC iniziale; le
fasi successive (LiDAR, dataset, bot backend, monetizzazione) sono
descritte nella PRD come riferimento.
